# ATIS24 

### What is ATIS24?
ATIS24 is a website that broadcasts live ATC24 ATIS (Automatic Terminal Information Service).
### What is ATC24
ATC24 is a popular, highly structured semi-realistic roleplay community built around the Roblox game Pilot Training Flight Simulator (PTFS). Instead of just flying planes casually, players in ATC24 use dedicated Discord voice channels to communicate 24/7 like real-world pilots and air traffic controllers.
### What is ATIS?
It is a continuous, pre-recorded audio or digital broadcast provided at busy airports. It gives pilots essential, up-to-date operational and weather data before they contact air traffic control (ATC).
### What is the point of ATIS24?
The real point is for realism. In IRL, pilots tune into a specific airport frequency where a TTS (text to speech) voice 24/7 broadcasts the ATIS info. In this website it does the same thing: You have to tune in to the aiport, wait for the ATIS to restart so you can hear the whole information.
